CLO4: Investigate Constraint Satisfaction Problems (CSPs).

This is an individual assignment.

The assignment emphasizes CSP modeling and reasoning, rather than writing a large program.

You will translate a scheduling problem into a formal CSP, reason about consistency, apply CSP heuristics manually, and analyze the effect of changing a constraint.

ImportantAssessment principle

You are expected to demonstrate that you understand variables, domains, constraints, consistency, backtracking, MRV, degree heuristic, LCV, and forward checking.

Answers without reasoning receive limited credit.

Scenario — University Exam Scheduling

A department must schedule six exams:

AI
Database
Networks
Security
Programming
Mathematics

The available timeslots are:

S1 = Monday Morning
S2 = Monday Afternoon
S3 = Tuesday Morning

The following conflicts apply:

  1. AI and Database cannot be scheduled at the same time.
  2. AI and Networks cannot be scheduled at the same time.
  3. AI and Security cannot be scheduled at the same time.
  4. Database and Networks cannot be scheduled at the same time.
  5. Database and Programming cannot be scheduled at the same time.
  6. Networks and Security cannot be scheduled at the same time.
  7. Networks and Mathematics cannot be scheduled at the same time.
  8. Security and Programming cannot be scheduled at the same time.
  9. Programming and Mathematics cannot be scheduled at the same time.

Additional restrictions:

  • AI can use only S1 or S2.
  • Networks can use only S2 or S3.
  • Mathematics can use only S1 or S3.
